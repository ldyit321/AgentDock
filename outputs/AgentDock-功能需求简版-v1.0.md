# AgentDock 功能需求简版

版本：v1.0 讨论稿｜日期：2026-10-28

本文仅描述第一版用户能做什么、系统提供什么功能，不涉及技术实现。是详细需求文档的简版，不表示功能已经开发完成。标注“建议”的内容仍待评审，其余细节以详细需求基线为准。

## 一、产品目标

一个多用户使用的 AI 助手网页。用户通过对话提出任务，AI 可以使用 Skill、调用 MCP 工具、编写和运行代码，返回回答和所需文件。

支持通用任务，不绑定特定行业或文件类型。

## 二、用户功能

| 功能 | 用户可以做什么 |
|---|---|
| 账号与个人空间 | 登录、退出；管理自己的对话和任务，个人数据与其他用户隔离。建议由管理员创建账号 |
| 多轮对话 | 新建对话、提出任务、继续追问、修改要求，并基于前面的结果继续处理 |
| 文件上传 | 提交任务时上传文件，也可以在后续对话中追加文件 |
| 图片与文档理解 | 图片实际交给多模态模型理解；文档解析文字、表格及必要页面图像，显示处理范围并可追溯原件 |
| 历史记录 | 查看过去的消息、任务过程和成果；继续对话时能够使用相关历史信息和文件 |
| 长对话接续 | 内容较长时整理上下文和摘要，保留原始记录；需要细节时回读相关消息、图片或文档页 |
| Skill 使用 | 使用管理员提供的公共 Skill，以及自己上传的 Skill |
| Skill 自动选择 | 让 AI 自动选择适合任务的 Skill，也可以手动限定可使用范围 |
| Skill 管理 | 上传 Skill、查看说明；建议支持更新、删除及版本查看，上传内容默认私有 |
| MCP 连接 | 配置和使用自己的 MCP 连接；建议支持连接测试、启停和断开，也可使用管理员授权的共享连接 |
| 代码与工具执行 | 让 AI 根据任务读取说明、使用脚本、编写和运行代码，或调用已授权的外部工具 |
| 失败处理 | 查看失败原因；可选让 AI 尝试修复代码并重新执行，达到限制后明确结束 |
| 结果与下载 | 查看最终回答、预览允许展示的结果、下载生成文件，并在下一轮继续使用这些成果 |
| 进度查看 | 查看任务正在做什么、是否等待回答、是否完成，以及简要执行结果 |
| 取消任务 | 建议支持取消正在执行的任务，保留已完成步骤和取消结果；已发生的外部操作不能保证撤销 |

## 三、Question Human：执行中向用户提问

当 AI 缺少必要信息或需要用户选择时，在当前对话中提出问题。

- 建议支持单选、多选、文本回答和补充文件。
- 用户回答后继续处理相关任务。
- 待回答问题可保留，刷新页面后仍可查看。
- 用户没有回答，不视为同意。

建议另设“操作确认”：发送、修改、删除等会影响外部系统的动作，按规则展示具体操作，由用户批准或拒绝。普通问答和操作确认分别记录。

## 四、Todo List：任务计划与进度

AI 在处理复杂任务时建立待办清单，让用户了解计划和进展。

- 展示待处理、进行中、等待用户、已完成等状态。
- 随任务进展新增、调整和更新步骤。
- 用户可以通过对话要求调整计划。
- 保留步骤调整及完成情况。
- 勾选完成不等于任务一定成功，仍需检查实际结果。

## 五、管理员功能（建议范围）

| 功能 | 管理员可以做什么 |
|---|---|
| 用户管理 | 创建账号、启停账号、分配使用额度 |
| 公共 Skill 管理 | 添加、发布、更新和停用公共 Skill |
| 共享 MCP 管理 | 配置共享连接，决定哪些用户能使用哪些工具 |
| 模型配置 | 统一配置 AI 模型服务，并支持后续更换模型 |
| 任务管理 | 查看任务排队、运行和异常情况，处理卡住或清理失败的任务 |
| 使用限制 | 设置并发数、运行时长、文件容量和重试次数等限制 |
| 访问策略 | 管理允许访问的外部服务，以及需要用户确认的操作 |
| 数据清理 | 设置文件和记录的保留规则，管理存储空间 |

管理员不默认拥有网页中任意浏览他人对话和文件的功能，具体管理权限待确认。

## 六、共同使用规则

- 用户只能访问自己有权限的任务、文件、Skill 和 MCP 连接。
- 建议私有 Skill 和个人 MCP 默认仅本人可用，公共 Skill 不附带管理员个人账号权限。
- 用户上传的 Skill 可以描述需要什么工具，但不能自动获得新的连接和权限。
- 对话和成果可以持续保留；临时运行环境在本轮结束后清理，下轮恢复所需文件继续处理。
- 建议任务超过并发上限时排队；超过运行或修复限制时结束并说明原因。
- 任务需要文件成果时检查文件是否有效；只需文字回答或查询结果的任务，不强制生成文件。
- 记忆首先服务于同一对话的连续处理；建议第一版不自动跨对话学习长期个人偏好。

## 七、建议暂不纳入第一版

- 公开注册、用户间分享私有 Skill。
- 自动跨对话长期记忆。
- 多个 AI Agent 相互协作。
- 用户上传命令后自动安装任意外部工具服务。
- 任务中断后无条件自动续跑，或自动撤销已完成的外部操作。

## 八、典型使用过程

登录 → 输入任务并上传文件 → AI 选择 Skill／工具 → 展示 Todo 并执行 → 必要时向用户提问或请求确认 → 展示结果并提供下载 → 用户继续追问或追加文件。

完整范围、决定状态及验收要求见 [详细需求与功能基线](AgentDock-需求与功能基线-v1.0.md)。
