## 在其他环境获取资料

```powershell
git clone https://github.com/ldyit321/AgentDock.git
cd AgentDock
```

文档内部使用仓库相对路径作为阅读入口，可在其他克隆位置阅读；实际Windows开发仍遵循当前D盘工程约束。历史报告中的绝对路径是当时环境证据，不是新机器必须照抄的配置。

`.env`、真实凭据、依赖环境、运行数据、回退暂存和外部Skill源码不在仓库里。新环境需要自行配置服务与凭据，不能假设克隆后已获得原电脑的OpenSandbox、MongoDB、模型或MCP连接。

## 版本与研发方式

- 需求文件名保留v1.0，但其后续用户决定继续有效。
- 技术设计v1.1及通用宿主补充是现行设计；旧v1.0技术稿只作历史参考。
- 实施节奏以v1.2计划及AGENTS.md为准；旧详细任务计划仅作技术拆分参考。
- 开始具体节点需用户明确授权；节点完成后交付报告，停下来等待验收与下一节点授权。
- 产品代码使用明确中文注释；提交说明使用中文，每次围绕一个可审查目的。

资料首次纳管按主题分批提交；较长现有文档保留完整，属于历史基线，不按代码行数机械切成残缺文档。
